JEGYZETAR C# DESKTOP APPLICATION, BY NORBERT BARANYI

----------Key Features----------

User Authentication
•	Secure login system
•	Session management with UserSession class
•	User profile display with initials
Note Management
•	Browse all available notes
•	Search notes by name, description, or tags
•	View detailed note information
•	PDF preview with PdfiumViewer library
•	Download notes to local storage (Documents\jegyzetar)
Favorites System
•	Add/remove notes to favorites
•	Real-time like counter
•	Visual feedback (❤️ liked / 💔 unliked)
•	Dedicated favorites view
Downloads
•	Local file management with .meta tracking
•	Automatic duplicate handling
•	View downloaded notes offline
•	Open in external applications



----------Configuration----------
!!!!	Connection String: Server=localhost;Database=jegyzetar;Uid=root;Pwd=;
!!!! ONLY WORKS ON LOCALHOST ATM
•	Download Path: %UserProfile%\Documents\jegyzetar



----------Dependencies----------
•	.NET Framework 4.7.2+
•	MySQL Server
•	PdfiumViewer NuGet package
•	MySql.Data NuGet package
